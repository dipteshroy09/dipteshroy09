### PlayHack ML Track — Sports Injury Prediction (IIT Guwahati)

A three-model CatBoost pipeline for athlete injury prediction built at the IIT Guwahati Sports Board × Technical Board hackathon. Predicts injury onset and recovery duration from a 30-day wearable observation window using 347 leakage-safe features across seven data sources (activity, sleep, heart rate, training sessions).

**Key finding:** Injury probability correlates −0.852 with true onset day, establishing a structural two-week physiological detection horizon — injuries occurring within the first 14 days of the risk window are detected at 94–97% recall with onset predicted to within ~1 day.

| Metric | Value |
|---|---|
| Task A — F1 | 0.5261 |
| Task B — Onset Skill | 0.6416 |
| Task B — Recovery Skill | 0.0857 |
| ROC-AUC | 0.7655 |

Evaluated under strict nested 5-fold cross-validation with per-fold baselines and zero data leakage.

**Core technologies:** Python · CatBoost · scikit-learn · Pandas · NumPy
